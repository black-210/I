# دليل التحديث الشامل: لغة الأنظمة الثنائية `I`
# The Language I Update Guide: Zero-Friction Ergonomics & Organized Deep Systems

---

## 📌 ملخص التحديث في سطور / Executive Summary

جاء هذا التحديث لحل معضلة أساسية واجهت المبرمجين في لغات الأنظمة:
> **"كيف نجعل لغة البرمجة سهلة وبديهية جداً لأي مبتدئ يبدأ بكتابة برنامجه الأول في ثوانٍ معدودة، دون التضحية بأي ذرة من التعقيد الهندسي والتحكم العتادي العميق المطلوب لبناء أنظمة التشغيل والبرامج الثابتة ومحركات البتات؟"**

تم تحقيق ذلك عبر تطبيق مبدأ **«التدرج المنظم للتعقيد» (Progressive Disclosure of Power)**:
1. **سطح سهل وبديهي (Easy Mode):** يتيح كتابة كود نظيف وبسيط باستخدام كلمات مألوفة (`fn`, `let`, `var`, `if`, `else`, `while`, `return`, `int`).
2. **عمق هندسي منظم (Deep Systems Mode):** يتيح التحكم الدقيق بسجلات المعالج ومنافذ العتاد (`@out8`..`@out32`)، والذاكرة الفيزيائية المباشرة (`@load8`..`@load64`)، وتخطيطات البتات المحزومة (`layout`), مع عقود الأمان الصارمة (`require cap`).
3. **حزمة VSIX رسمية محدثة (`i-language-0.1.0.vsix`):** توفر إكمالاً تلقائياً ذكياً وشروحات تفاعلية عند التمرير باللغتين العربية والإنجليزية لضمان عدم الحاجة لحفظ أي شيء.

## 1. الكلمات المفتاحية الجديدة والبدائل السهلة (Intuitive Aliases)

أصبح بإمكانك كتابة الكود بأي من الأسلوبين، والمترجم يفهمهما بالتساوي وينتج نفس كود الآلة بدقة 100%:

| الكلمة السهلة الجديدة | الكلمة الأصلية | الدور الوظيفي | ما يفعله المعالج (Under the Hood) |
| :--- | :--- | :--- | :--- |
| **`fn`** | `routine` | تعريف دالة أو إجراء | يولد إطار مكدس x86-64 القياسي ويخصص السجلات |
| **`let`** | `bind` | تعريف قيمة ثابتة (Immutable) | حجز قيمة ثابتة تمنع الآثار الجانبية في وقت الترجمة |
| **`var`** | `mut` | تعريف متغير محلي (Mutable) | تخصيص مساحة محلية في المكدس بالنسبة لـ `[RBP - offset]` |
| **`if`** | `branch` | تفرع شرطي | مقارنة عتادية `CMP` متبوعة بقفز مشروط `JZ/JNZ` |
| **`else`** | `otherwise` | المسار البديل للشرط | قفز غير مشروط `JMP` لتخطي كتلة الشرط الأول |
| **`while`** | `cycle` | حلقة تكرار بسيطة | فحص الشرط والقفز العكسي `JMP rel32` حتى انتهاء التكرار |
| **`return`** | `yield` | إرجاع الناتج من الدالة | وضع الناتج في سجل `RAX` وتنفيذ تعليمة العودة `RET` |
| **`assert`** | `verify` | فحص عقد في وقت الترجمة | تقييم فوري للشرط الثابت وفشل التجميع عند الخطأ |

## 2. الأنواع السهلة والاستنتاج التلقائي (Type System Simplification)

### أ. الأسماء البديهية المألوفة:
- **`int`** : عدد صحيح 32 بت موقّع (بديل لـ `i32`).
- **`uint`** : عدد صحيح 32 بت غير موقّع (بديل لـ `u32`).
- **`byte`** : بايت غير موقّع 8 بت [0..255] (بديل لـ `u8`).
- **`bool`** : قيمة منطقية ممثلة في بايت (0 أو 1).
- **`short`** : عدد صحيح 16 بت (بديل لـ `i16`).
- **`long`** : عدد صحيح 64 بت (بديل لـ `i64`).

### ب. إمكانية تجاوز تحديد النوع للمتغيرات (Type Inference):
لم يعد المبتدئ مجبراً على كتابة النوع إذا كانت القيمة واضحة:
```i
// في السابق:
bind a: u32 = 10;
mut b: u32 = 20;

// الآن أصبح بإمكانك كتابة:
let a = 10;
var b = 20;
```
يقوم المترجم تلقائياً بتحديد نوع المعالج الافتراضي (`u32` / `int`) بأمان حتمي.

## 3. توسيع وترتيب الدوال العتادية والذاكرة الفيزيائية (Expanded Hardware Intrinsics)

للمهندسين ومطوري النواة، تم توسيع مكتبة الدوال الداخلية المباشرة لتشمل كافة عروض البيانات في الذاكرة والمنافذ:

### أ. منافذ الإدخال والإخراج العتادية (Hardware Port I/O):
تتطلب تصريح `require cap: hardware_io;`:
- `@out8(port, val)` : إرسال بايت (8 بت) لمنفذ عتادي (`OUT DX, AL`).
- `@in8(port) -> u8` : قراءة بايت (8 بت) من منفذ عتادي (`IN AL, DX`).
- `@out16(port, val)` : إرسال كلمة (16 بت) لمنفذ عتادي (`OUT DX, AX`).
- `@in16(port) -> u16` : قراءة كلمة (16 بت) من منفذ عتادي (`IN AX, DX`).
- `@out32(port, val)` : إرسال كلمة مضاعفة (32 بت) لمنفذ عتادي (`OUT DX, EAX`).
- `@in32(port) -> u32` : قراءة كلمة مضاعفة (32 بت) من منفذ عتادي (`IN EAX, DX`).

### ب. الوصول المباشر للذاكرة الفيزيائية والمؤشرات (Raw Pointer Access):
تتطلب تصريح `require cap: raw_memory;`:
- `@load8(addr)` / `@store8(addr, val)` : قراءة/كتابة بايت 8 بت في أي عنوان فيزيائي.
- `@load16(addr)` / `@store16(addr, val)` : قراءة/كتابة كلمة 16 بت.
- `@load32(addr)` / `@store32(addr, val)` : قراءة/كتابة كلمة 32 بت.
- `@load64(addr)` / `@store64(addr, val)` : قراءة/كتابة كلمة رباعية 64 بت.

### ج. التحكم بحالة المعالج والنواة:
- `@cli()` : تعطيل المقاطعات العتادية (`CLI`).
- `@sti()` : تفعيل المقاطعات العتادية (`STI`).
- `@hlt()` : إيقاف المعالج المؤقت بانتظار مقاطعة (`HLT`).
- `@cpuid()` : فحص إمكانيات وميزات المعالج (`CPUID`).
- `@syscall(...)` : نداء مباشر لنواة نظام التشغيل المضيف (`SYSCALL`).

## 4. مقارنة بصرية جنباً إلى جنب (Side-by-Side Comparison)

### برنامج المبتدئ السلس (Easy Mode):
```i
fn max_number(a: int, b: int) -> int {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}

fn main() -> int {
    let x = 100;
    var y = 250;
    return max_number(x, y);
}
```

### برنامج مهندس النواة المنظم (Deep Systems Mode):
```i
system KernelModule;

require cap: hardware_io;
require cap: kernel_ring0;

layout Uart16550 {
    rbr_thr: u8 @ 0x00,
    ier:     u8 @ 0x01,
    fcr:     u8 @ 0x02,
    lcr:     u8 @ 0x03,
}

kernel_entry _start() -> void {
    @cli();
    @out8(0x3F8, 0x48); // 'H'
    @out8(0x3F8, 0x49); // 'I'
    halt;
}
```
**كلا الكودين يترجمان لنفس كود الآلة الصافي بأقصى درجات الكفاءة والسرعة!**

## 5. ما الجديد في إضافة Visual Studio Code (`i-language-0.1.0.vsix`)؟

1. **إكمال ذكي غير متعارض (IntelliSense):**
   - يقترح الكلمات السهلة فوراً بمجرد كتابة أول حرف (`f` -> `fn`, `l` -> `let`, `v` -> `var`, `i` -> `if`).
2. **توثيق وشرح فوري عند التمرير (Hover):**
   - ضع الفأرة على أي كلمة لترى فوراً شرحاً عربياً وإنجليزية يوضح لك عملها وماذا تفعل في مسجلات المعالج مع كود توضيحي.
3. **قوالب جاهزة (Snippets):**
   - قوالب فورية للدوال، الحلقات، الشروط، ومشغلات الأجهزة، والإقلاع العتادي.
4. **كيفية التثبيت:**
   - من الطرفية:
     ```bash
     code --install-extension i-language-0.1.0.vsix
     ```
   - أو مباشرة من زر **Download VSIX Extension** المتاح في واجهة التطبيق.
