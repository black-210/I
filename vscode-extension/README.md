# Language `I` Extension for Visual Studio Code

Official VS Code extension for the **`I` Pure Binary Systems Programming Language**.

## Features

- **Rich IntelliSense Auto-Completion:** Instant completions for every keyword, type, hardware intrinsic, capability token, and operator.
- **Hover Explanations in Arabic & English:** Hover over any keyword, intrinsic, or operator to see detailed machine explanations, registers affected, and code examples without needing to memorize syntax.
- **Smart Non-Conflicting Snippets:** Full templates for kernel bootloaders, 16550 UART drivers, constant-time cryptography primitives, and INT8 quantized AI kernels.
- **Syntax Highlighting:** TextMate grammar supporting binary bit literals (`0b1011_0001:b8`), checked operators (`+!`, `+%`, `+?`), and hardware intrinsics (`@out8`, `@cli`, `@hlt`).

## Installation

Install via VS Code CLI:
```bash
code --install-extension i-language-0.1.0.vsix
```
Or via VS Code UI: `Extensions` -> `...` -> `Install from VSIX...`
